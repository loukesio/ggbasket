# Plot win probability added in one game

Plot win probability added in one game

## Usage

``` r
plot_wpa(
  wpa,
  game = NULL,
  colours = NULL,
  title = NULL,
  subtitle = NULL,
  caption = NULL
)
```

## Arguments

- wpa:

  Output of
  [`win_probability_added()`](https://loukesio.github.io/ggbasket/reference/win_probability_added.md).

- game:

  `game_id`.

- colours:

  Named vector of team colours (default: blue and orange).

- title, subtitle, caption:

  Labels.
