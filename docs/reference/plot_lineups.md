# Plot line-ups

The best and worst five-player units by net rating, with minutes played.

## Usage

``` r
plot_lineups(lu, n = 6, title = NULL, subtitle = NULL, caption = NULL)
```

## Arguments

- lu:

  Output of
  [`lineups()`](https://loukesio.github.io/ggbasket/reference/lineups.md).

- n:

  Units at each end.

- title, subtitle, caption:

  Labels.
