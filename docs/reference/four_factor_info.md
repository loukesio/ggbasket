# Names, direction and Oliver weights of the four factors

A lookup table used by
[`plot_four_factors()`](https://loukesio.github.io/ggbasket/reference/plot_four_factors.md):
one row per factor and side with the column name, a label, whether
higher is better for the team, and Dean Oliver's approximate weight
(40/25/20/15).

## Usage

``` r
four_factor_info()
```
