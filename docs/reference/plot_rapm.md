# Plot RAPM: the top and bottom players

Plot RAPM: the top and bottom players

## Usage

``` r
plot_rapm(
  rp,
  n = 12,
  highlight = NULL,
  title = NULL,
  subtitle = NULL,
  caption = NULL
)
```

## Arguments

- rp:

  Output of
  [`rapm()`](https://loukesio.github.io/ggbasket/reference/rapm.md).

- n:

  Players shown at each end.

- highlight:

  Players to colour.

- title, subtitle, caption:

  Labels.
